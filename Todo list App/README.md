# 📝 Todo List App

A simple and responsive Todo List application built using **HTML, CSS, JavaScript, and Tailwind CSS**. This project helped me revisit core JavaScript concepts by building something practical instead of only reading theory.

## ✨ Features

* Add new tasks
* Delete tasks
* Mark tasks as completed
* Automatically save tasks using Local Storage
* Theme support (Light, Dark, and System mode)
* Responsive user interface
* Task statistics (Total and Completed tasks)
* Empty state placeholder when no tasks exist

## 🛠️ Technologies Used

* JavaScript (Vanilla JS)
* Tailwind CSS

## ⚙️ How It Works

### Creating Tasks

When the user submits the form, JavaScript creates a new task dynamically and adds it to the page.

### Saving Tasks

Every change (adding, deleting, or completing a task) is saved to **Local Storage**, so tasks remain available after refreshing the page.

### Loading Saved Tasks

When the application starts, it reads the saved tasks from Local Storage and displays them automatically.

### Theme Support

Users can choose between:

* ☀️ Light Mode
* 🌙 Dark Mode
* 💻 System Theme

The selected theme is also saved in Local Storage.

### Task Statistics

The application automatically updates:

* Total Tasks
* Completed Tasks

whenever a task is added, deleted, or marked as complete.
